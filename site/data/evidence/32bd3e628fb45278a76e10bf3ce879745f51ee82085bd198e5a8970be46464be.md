# 计算、费用与识别规则

对每分钟观测到的最早毫秒，保存全部价格的最小和最大值 `Omin/Omax`；最晚毫秒同理为 `Cmin/Cmax`。不使用 trade ID 或文件物理顺序推定同毫秒真实先后。物理顺序对应的 K 线开收价只作描述性对照。分钟首末恰为同一毫秒的情况本样本为 **0**；一般若存在，该端点矩形也仅是更宽松的包络，不能保证两个端点的先后可实现。

`q=0.01 BTC`；每腿摩擦率 `r=(手续费bps+滑点bps)/10000`。预定情景依次为 0+0、1+1、5+2、10+5 bps；在进入和退出各扣 `q×对应价格×r`。这些是预设现金摩擦情景，不是查证的实际收费等级、撮合滑点或执行价格。

- 多方向价格减摩擦分量：`q×[(1-r)C-(1+r)O]`；下界取 `Cmin/Omax`，上界取 `Cmax/Omin`。
- 空方向价格减摩擦分量：`q×[(1-r)O-(1+r)C]`；下界取 `Omin/Cmax`，上界取 `Omax/Cmin`。
- 下界大于零才是“确定正”；上界小于零才是“确定负”；两端等于零为“确定零”；其余跨零或触零为“符号未定”。

这些区间只覆盖**所观测边界价格集合与明确摩擦公式的条件结果**；不覆盖缺失事件、真实排队、可成交量、报价价差、资金费或标记价格风险，不是概率区间，也不是实际可成交损益极值。没有可执行信号，没有选出交易方案，各分钟独立作诊断，不合计成一个组合收益。做多、做空亦不相加。

资金费**未纳入**本分量，绝不因此假定为零。官方说明实际资金费 assessment 可能持续到一分钟，合约频率也可能调整；一分钟代理不能自行证明不会承担资金费。标记价格与最新成交价职责不同，成交开收不能补成结算 mark 或完整 mark 路径。[资金费规则](https://www.okx.com/en-sg/help/perps-funding-fee-mechanism)、[标记价格与最新成交价](https://www.okx.com/help/ii-mark-price-and-last-price)
