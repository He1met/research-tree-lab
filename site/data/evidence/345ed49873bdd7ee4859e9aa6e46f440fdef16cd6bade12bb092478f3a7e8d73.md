# 认识与限制

1. 实际 CSV 的字段、单位关系、日期分区与分钟聚合已获得真实文件证据，修复了此前“只见 UI 字段、未解码目标成交 CSV”的资料缺口。
2. 连续 ID、CRC、分钟无缺口及 K 线完全一致均不能证明交易所事件全集完整。两份文件来自同一发布者，也不是两个独立来源。
3. 实际同毫秒多价使先后不确定性具体化。文件顺序、ID 递增、K 线一致都不能替代官方排序语义；不能据此指定原方案可执行的 first trade。当前能证明的是观察到的顺序和聚合结果。
4. 成交价与 K 线都不是精确结算 mark。旧方案需要的每次结算标记、完整 mark 路径、实际资金费及实际费用仍分别核对，不用 close 或最近价代替，不填零。
5. 本次日期是历史开发信息，不覆盖原方案 2026-09-23 / 24 的未来进出窗口。旧方案仍按原规则等待每日复核；本结果不会提前给经济结果或改旧分数。
6. 2 天延迟是既有 UI 声明；本轮没有测得完整发布 SLA，上游实际发布时间未知。实际手续费、实际成交、净收益及账户适配均未知。
