# 指数成分失效：报价不变也会改变参考值吗？

本轮完成一个独立的指数构造边界研究。官方规则确认陈旧来源会被排除；两家有效来源时转为等权，因此“剔除后总按原权重归一化”不能通用于OKX。12个事前冻结合成算例验证一般加权均值恒等式，4例非零、8例零；它们不是真实BTC/ETH指数或收益样本。历史成分与失效事件未取得，actual_net为null，A/B仍PREPARATION_ONLY，自然触发UNKNOWN。

## 问题与最小实验

问题：其余报价不变时，成分失效能否使指数移动？比较集合在查阅外部资料前冻结：三报价90/100/110和全平100/100/100，权重1:1:1与1:2:1，逐一移除三个位置，保留全部12例。原均值与删除后保持剩余相对权重的均值作比较。不筛赢家，不加行情日或阈值。

令原归一化权重为w，移除成分价为p，原均值为I，则在剩余价格和相对权重不变时：

`I_after - I = w/(1-w) * (I-p)`

|冻结报价/权重|删除低价|删除中价|删除高价|
|---|---:|---:|---:|
|90/100/110；1:1:1|+5|0|-5|
|90/100/110；1:2:1|+10/3|0|-10/3|
|100/100/100；两组权重|0|0|0|

表中均是合成指数单位。7个手算/非法输入检查先通过，随后12例按有理数计算并用总额减去移除项再核对，属于同作者计算检查，无独立审查。零变动反例全部保留。通用恒等式只证明有限数学机制，不能证明目标历史指数曾如此移动。

## 真实资料核对与反证

[OKX Index Prices](https://www.okx.com/help/i-spot-index-prices)（页面更新2026-09-11）说明：维护或陈旧来源不参与计算；至少三家时使用预设权重并调整异常价，两家时等权，一家时取该价。具体陈旧期限依指数而异，部分成分和权重可能不公开。

[官方权重调整FAQ](https://www.okx.com/help/index-components-weightage-adjustment-faq)（页面更新2026-08-05）描述权重与成交量/流动性的关联及限偏幅度变化；具体指数生效批次需另查公告。当前权重入口不是历史有效版本证明。两个页面对中位数集合的措辞也不完全一致，不能据此猜历史算法。

因此，原先固定的“不变剩余权重归一化”模型不能升级为交易所复算器。尤其1:2:1删除端点后剩余权重不等，而官方两来源分支使用等权。90/100/110的价格差也可能触发异常价处理，本轮未实现该处理，所有上述数值均不得冠以官方指数结果。这个不适用结论保留，不事后重写算例来制造吻合。

由资料和恒等式推得的有限认识是：参考指数变化应检查成分有效性和权重切换，不能仅归因于保留报价的变化。它是机制推论，不是历史事件实证，也不是交易信号或可成交价格。
