## 验收摘要
验收的核心不是模板是否齐全，而是新研究能自动出现在真实React Flow页面，后续复核能更新原轮次并推动下一代，所有历史和执行条件标志可追溯。合成测试、真实小样本、自然定时、公开发布、恢复及经济证据分别验收。尚未发生的未来窗口不能用手工触发或补数据冒充。

# 首版与长期验收清单

以下均为生产实现要求；本包参考脚本通过的项目不等于下面全表通过。

## A. 研究目标与接续

| ID | 场景 | 通过要求 |
|---|---|---|
| A01 | 没有任何历史复核 | 可以从官方资料/数据调查独立启动真实研究 |
| A02 | 原方向等待未来数据 | 其他有意义方向继续，等待不成为全局锁 |
| A03 | 同机制改名或同数据重复尝试 | 去重/标变体/合法复现，不虚报新机制 |
| A04 | 有价值新方向长期被延后 | 真实获得执行或明确不可行证据，不只改优先级数字 |
| A05 | 有开发支持的方向 | 后继至少实际检查一种成本/反例/暴露/边界/新样本，而非只有调参 |
| A06 | 已完成反馈 | 新研究引用原feedback并实际采用、检验或解释不采用 |
| A07 | 原假设在一类状态失败 | 暂停范围准确，留下新证据重启条件，不推广到所有市场 |
| A08 | 用户不读网页不回复继续 | 原生任务仍接续，不形成普通研究审批 |

| B05 | 最终与阶段 | 到原终点且数据齐全才最终；等待/缺数/未触发分别表示 |
| B06 | 路径歧义 | 同K线触发先后按预登记或报告未知/范围，不择优 |
| B07 | 费用与网格 | 未知不填0；库存/未实现/资金费/退出纳入，手算样例核验 |

| B11 | 重叠独立方案 | 不相加为账户利润，样本角色和相关性说明 |

## C. React Flow与自动数据展示

| ID | 场景 | 通过要求 |
|---|---|---|
| C01 | 真实组件 | 安装并构建实际@xyflow/react；原生HTML不能冒充 |
| C02 | 两代分叉与多日复核 | 第一轮内部P/R/F，下一代在下一列；复核不增代 |
| C03 | 两种展开 | 本轮材料与后继可分别展开，不相互隐藏 |
| C04 | 多候选 | 显式主选引用；无主选分开列，不取第一项或赢家 |
| C05 | 新结果接入 | 追加完整记录后运行发布逻辑即可出现；web/src哈希不因加记录变化 |
| C06 | 历史搜索 | 能搜折叠/未加载记录，显示祖先；未加载不等于不存在 |
| C07 | 每日复核入口 | 按批次/日期/产品查看，点入具体review版本并定位轮次 |
| C08 | 历史时点 | 旧快照不含未来产品、修订、解释和采用状态 |
| C09 | 新快照 | 用户视窗/选中不被抢；失败保留旧快照并明确陈旧 |
| C10 | 手机和只读 | 390px可读；键盘/Escape可用；无账户/审批/交易/改图动作 |
| C11 | 实际规模 | 分别测试总历史1000/10000记录与可见50/100/200节点，记录实际设备/浏览器和问题；档位不是产品上限 |
| C12 | 前端安全 | 文本/Markdown转义或安全白名单，无任意HTML执行、路径逃逸或敏感下载暴露 |

## D. 执行条件标志

- D01：规则完整但只有参考数据或陈旧数据，只能可回放/研究，不高亮当前执行。
- D02：某候选盈利但缺执行事实，不能升格；负结果也不自动决定市场规则完整性。
- D03：满足全部有证据的检查、当前触发与有效窗口时，具体plan显示“具备交易执行条件 · 截至…”，同处保留证据阶段。
- D04：重新发布页面不能延長证据有效期。有效期到达前端即降级；缺有效时点保持未知。
- D05：一个轮次仅一方案满足时，不给整轮其余候选统一高亮。
- D06：假数据、字段缺失、失效/纠错、未知schema不能高亮生产标志。
- D07：账户适配始终未评估；无下单/资金操作；有效期到期不声称已经平仓。

## E. 存储、并发、发布与恢复

- E01：同ID同内容重放幂等，异内容冲突拒收，已封存字节不被改写。
- E02：写入一半中断，没有完成manifest不参与正式评价；恢复只续缺项。
- E03：两个并行研究独立写；两个相同任务不能同时成为同问题owner；旧owner不能覆盖新owner。
- E04：研究/复核不直接git操作公共HEAD；公共发布短暂单写，不长锁计算。
- E05：数据一次共享、多轮引用；临时worktree删除后原档仍在稳定根。
- E06：公开镜像、网页投影可从原件重建；同输入生成一致；全历史索引与大文件链接可追溯。
- E07：公开前秘密/许可检查，普通摘要不能代替未备份原件；嵌套包不绕过扫描。
- E08：发布中断只补发；不能重抽原模型结果。不完整snapshot不会成为latest。
- E09：实际打开Pages并核对snapshot后才记发布确认；部署前不声称已上线。
- E10：从一个新目录恢复一项允许公开的完整研究，验证代码/数据/结果与清单；尚未远端保存的部分如实标明。
- E11：升级读取器仍能读旧schema；未知新格式明确不支持，不静默丢历史。
- E12：缓存清理排除在途、被引用、未备份唯一资料；恢复目录不递归纳入备份。

## F. 原生任务与权限

- F01：四真实任务有可回读ID、正文、路径、频率/时区、模型与权限。意图JSON不算安装。
- F02：管理能力不可用时明确缺项与一次性UI操作，不编辑产品内部数据库、不用CLI/API回退。
- F03：权限分别记录工作约定、程序检查和环境强制；测试哨兵证明实际边界，不能凭提示词宣称只读隔离。
- F04：真实复核能写自己的结果，但无覆盖原件路径；发布仅访问本项目获准仓库；若原生边界达不到，标明弱隔离并拒收越界结果。
- F05：改变用户频率后不被配置重置；同一项目去重，不改变其他项目任务。
- F06：单项权限、配额或数据问题不让无依赖研究全部停止；没有额度不推算余额或无限重试。
- F07：手动试跑、自然运行分开；至少两个不同自然研究时点、一轮自然日复核和真实后继有证据。
- F08：长任务有实际进展继续；失联只调查确认的本项目对象，未有控制能力不假称重启。
- F09：整个Mac/App停更时网页陈旧，不假称远程能自救；必要认证由用户一次处理，普通研究不需要审批。
