# 新项目实施包

## 方案摘要
本包把自动策略研究、每日复核、React Flow研究树、历史自动展示、执行条件标志和四类定时任务合成一套可实施规格。用户将其放入已建新项目，发给Codex总提示词；日常不维护页面数据、不审批研究。所有实际环境、数据、任务和发布仍需由Codex在Mac验证。

日期：2026-09-23。

## 你只需要做的事
将本目录完整放进新项目的独立planning/current/位置，避免覆盖当前AGENTS或代码；向该项目的Codex发送FIRST_MESSAGE.txt。文件中的项目名是逻辑名称，实际目录和仓库以现场为准。已经有文件或代码就检查后增量实现，不清空重建。

## 入口
- PROJECT_SPEC.md：唯一总规格，含需求汇总、数据保存、UI、标志、长期维护。
- RESEARCH_PROGRAM.md：首批机制、具体研究模板、宽度深度与每日复核。
- AUTOMATIONS.md：四类任务、建议频率、读写权限、创建与回读步骤。
- FIRST_MESSAGE.txt：用户可直接发送的总实施提示词。
- prompts/：四个可直接粘贴到原生任务的完整正文与创建总指令。
- .agents/skills/：四个项目级工作方法。由Codex核对安装到真实项目根，不重复注册同名Skill。
- config/：产品意图、任务意图、标志策略。task ID为null，表示未创建。
- examples/：合成三轮研究及复核/反馈输入；不是市场数据或真实任务。
- reference/：小型纯Python参考转换器，示范从记录生成网页JSON及自动标志。不联网、不调模型、不模拟市场、不发布网站。
- docs/ACCEPTANCE.md：端到端、并行、历史、权限和恢复验收。
- VALIDATION.md：本次真实检查范围与尚未实现部分。

参考输出在examples/generated/。展示数据应由程序形成，而不是让AI改React卡片。参考实现不替代生产校验器；Codex需增加真实文件封存、数据获取、回放、任务和React Flow代码。

本包未包含第三方前端库、字体、凭据或真实交易数据。只提供文本规范、合成记录与自有参考代码。不得把通过参考测试写成完整项目已经上线。
